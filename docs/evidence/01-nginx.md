# Nginx Reverse Proxy & Security Headers

## Cau hinh
- Nginx reverse proxy den CRM Web.
- File cau hinh: nginx/nginx.conf
- Docker Compose: docker-compose.yml

## Kiem tra
Mo website:
http://localhost:8080

Kiem tra Security Headers:
curl.exe -I http://localhost:8080

## Minh chung can chup
1. Website CRM Care chay qua Nginx.
2. Terminal hien thi HTTP Security Headers.
3. File nginx/nginx.conf trong VS Code.
